## 換成真實資料的格式

`data/songs.json` 是一個陣列，每一首歌長這樣：

```json
{
  "id": "s0001",
  "title": "至少還有你",
  "album": "林憶蓮's",
  "lang": "國語",
  "cover": "images/album-lin-yilians.jpg",
  "coverConfirmed": true
}
```

`coverConfirmed` 是給我們自己追蹤用的欄位（true = 已換成真封面，false = 還是佔位圖），
遊戲本身不會用到這個欄位，可以自由增減。

如果你手邊有清楚的專輯封面圖檔（照片、截圖都可以），直接傳給我，
我就能省去自動搜圖可能找錯版本封面的風險，最快最準。

欄位說明：
- `id`：每首歌唯一代號，隨便取但不能重複（建議用 `s0001` 這種流水號）。
- `title`：歌名。
- `album`：專輯名稱（會顯示在卡片上）。
- `lang`：語言分類，目前程式沒有用到，先留著方便你之後排序/篩選。
- `cover`：封面圖片路徑。**建議把封面圖片實際下載放進 `images/` 資料夾**，
  用相對路徑指過去（不要直接連到外部網站的圖片網址）。原因：
  1. 外部圖床常會擋「hotlink」，圖片可能顯示不出來。
  2. 產生「晉級戰績圖」的功能需要用 canvas 讀取圖片，圖片必須跟網頁同一個網域，
     不然瀏覽器會擋下來，圖沒辦法輸出。

## 資料整理進度

等你把每張專輯的曲目複製給我之後，我會：
1. 幫你整理成上面的 JSON 格式。
2. 找到每張專輯的封面圖，下載成檔案放進 `images/` 資料夾（找不到的會列清單問你）。
3. 把 `data/songs.json` 換成正式版，直接覆蓋這個示範檔即可上線，其他都不用動。

## 部署到 Netlify

最簡單的方式（不需要任何指令）：
1. 打開 https://app.netlify.com/drop
2. 把整個 `sandy-tournament` 資料夾拖進網頁裡
3. 幾秒鐘後就會拿到一個網址，直接分享出去就能玩

之後要更新資料（例如換上正式版 `songs.json`），只要把整包資料夾重新拖拉上傳一次即可。

如果想要一個固定網址、之後改資料也能自動更新，也可以改用「連接 GitHub repo」
的方式部署，我可以再幫你設定 GitHub Actions 自動部署流程。
